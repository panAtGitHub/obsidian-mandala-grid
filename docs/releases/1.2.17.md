# 1.2.17

## 改进

- 升级到修复安全问题的 Svelte 5.57.2，并迁移组件挂载与销毁流程。
- 更新 nanoid 和 CSS 构建依赖，移除未使用的 diff 依赖。
- 更新 Obsidian 开发 SDK 的 moment 依赖到 2.31.0。
- 清理冗余类型断言，启用严格绑定调用检查。
- 使用 Obsidian DOM 创建辅助方法，并保留弹出窗口的文档归属。
- 修正类型导入、HTML 标签和跨组件样式作用域，增加组件运行时回归测试。

## Improvements

- Upgrade to patched Svelte 5.57.2 and migrate component mounting and cleanup.
- Update nanoid and CSS build dependencies, and remove unused diff dependencies.
- Patch the Obsidian development SDK's moment dependency to 2.31.0.
- Remove redundant type assertions and enable strict bind/call checking.
- Use Obsidian DOM creation helpers while preserving popout document ownership.
- Correct type imports, HTML tags and cross-component CSS scope, and add compiled
  component lifecycle regression coverage.
