# Mandala Grid 1.2.14

Fixes release metadata that prevented installation through the Obsidian community directory.

-   Aligns package, lockfile, manifest, and compatibility metadata on version 1.2.14.
-   Rejects invalid version formats and mismatched release tags before release assets are uploaded.
-   Generates GitHub build provenance attestations for the exact uploaded plugin assets.
-   Merges duplicate active parent and sibling CSS rules while retaining their styling.
-   Saves edits from embedded and detached views, including dashboard popovers. Thanks to BoltLi for [PR #3](https://github.com/panAtGitHub/obsidian-mandala-grid/pull/3).

Requires Obsidian 1.7.2 or later. Desktop and mobile remain supported.
