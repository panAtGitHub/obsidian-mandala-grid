# 1.2.16

## 修复

- 修复从单格原生编辑器保存并返回九宫格后，部分可见格子无法点击的问题。返回时补齐当前九宫格的交互节点，无需翻页恢复。
- 保持按需加载，仅加载当前九宫格所需的节点。

## Fixes

- Fix unresponsive visible cells after saving a cell in the native editor and returning to the grid. The current grid's interaction nodes are loaded automatically, without requiring navigation to another grid.
- Preserve on-demand loading by materializing only the nodes needed for the current grid.

Minimum Obsidian version: 1.13.0.

iPhone device verification is pending; the underlying state mismatch has been reproduced and verified in desktop Obsidian, with focused regression tests.
