# Mandala Grid 1.2.15

-   Requires Obsidian 1.13.0 or later on desktop and mobile.
-   Uses the public language API directly and removes legacy fallbacks and forbidden review-rule suppressions.
-   Registers language, presets, view switches, range limits, and time-plan settings with Obsidian's declarative settings API so they appear in settings search.
-   Uses native settings groups and preserves the three-column preset buttons and bounded label scaling.
-   Preserves store-based settings persistence, range validation, and live previews without interrupting text input.
-   Prevents reapplying a preset from flipping view switches that already match.
-   Removes the deprecated slider tooltip call; Obsidian displays slider values inline.

中文：最低 Obsidian 版本提高到 1.13.0，直接使用官方语言 API，移除旧版本兼容逻辑和禁止的审查规则屏蔽。
中文：迁移到新的设置 API，支持设置搜索，保留预设按钮布局、文字缩放、设置保存和范围实时预览。
中文：修复重复选择相同预设时可能错误翻转视图开关的问题。
