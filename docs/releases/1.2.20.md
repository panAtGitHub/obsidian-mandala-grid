# Mandala Grid 1.2.20

## 中文

- 改进日计划模板标题编辑、日期范围更新及周视图控制。
- 新增内置生活领域模板和顺时针布局预设；模板标题以 Markdown 标题插入。
- 增加独立的颜色标识透明度设置，修复颜色混合、选中格子和编辑器配色。
- 调整桌面工具栏、侧边栏、内容边距与详情预览。
- 增加设置帮助说明并统一选项字号，清理关闭后遗留的弹窗。
- 本地插件同步目标更新为 C:\iWork\obsidian；保留 data.json。
- 最低 Obsidian 版本保持为 1.13.0。

## English

- Improve day plan template title editing, date range updates, and week view controls.
- Add a built-in life areas template and clockwise layout preset; insert slot titles as Markdown headings.
- Add independent color indicator opacity and fix repeated blending, active cell colors, and editor colors.
- Refine desktop toolbar, sidebars, content gutters, and detail previews.
- Add contextual settings help, align option font sizes, and clean up detached modals.
- Update the local sync destination to C:\iWork\obsidian while preserving data.json.
- Minimum supported Obsidian version remains 1.13.0.
