# Mandala Grid 1.2.19

## 中文

- 修复 Svelte 5 升级后场景刷新循环导致电脑和手机九宫格无法操作的问题。
- 场景只在收到新数据时刷新；相同的场景标识不再重复回传给父组件。
- 新增实际场景宿主的编译运行回归测试，覆盖父子组件反馈、连续刷新、场景切换和重新打开。
- 修复按需加载首次打开时丢失 YAML、数据替换后格子不刷新，以及新增格子的预览编号与编辑编号不一致的问题。
- 恢复日计划可见日期的八格模板、日期翻页和回到今天；已有核心不再受新增核心的范围限制阻挡。
- 最低 Obsidian 版本保持为 1.13.0。

## English

- Fix a scene update feedback loop after the Svelte 5 migration that made desktop and mobile grids unresponsive.
- Refresh scenes only when their incoming projection changes and publish committed scene keys only when their values change.
- Add compiled scene host regression coverage for parent binding feedback, repeated refreshes, scene switches, and reopening.
- Preserve incoming YAML during indexed bootstrap, refresh derived stores after snapshot replacement, and use live node IDs after structural edits.
- Prepare the visible day's eight slots, restore date navigation and today jumps, and allow navigation to existing cores beyond creation limits.
- Minimum supported Obsidian version remains 1.13.0.
