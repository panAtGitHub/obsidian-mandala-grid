# 九宫格书写预设实施说明

本文件用于交接实现。开始前先读 [AGENTS.md](../AGENTS.md) 和 [使用场景与数据规则](design-guide.md)。这项功能有两个入口行为。书写预设在用户打开空格编辑时准备 Markdown 草稿。「统一当前文件格子格式」由用户另行点击和确认，才会处理已经填写的格子。

## 1. 全局默认和文件设置

| 入口 | 界面 | 生效范围 |
| --- | --- | --- |
| 图 1，插件设置 → 全局视图 | 在「当前范围总览」下方加「为新建文件启用格子书写预设」总开关，默认关闭 | 开启后，插件新建的九宫格 `.md` 写入默认预设。此后每份文件按自己的 YAML 生效 |
| 图 2，命令面板 | 沿用「更改当前九宫格文件设置」 | 打开下述文件设置页 |
| 图 3，九宫格视图选项 | 沿用「当前文件设置」 | 打开与图 2 相同的文件设置页 |

旧九宫格 `.md` 同样可以从文件设置页开启预设。原来没有预设字段时，文件开关显示关闭，用户打开后可以直接采用内置默认值，也可以逐层修改。修改全局开关只影响之后由插件创建的文件。文件开关可以独立开启或关闭，与全局开关的当前状态无关。

在现有文件设置页加入「格子书写预设」区域，使用现有 `Setting` 控件和中英文文案约定。

- 文件级总开关。开启时显示或启用各层控件。
- 每个单独配置的层级占一行，显示层级、示例编号、标题级别和正文形式。行数与当前文件的「子九宫最大层级（含核心层）」联动，具体见下一节。用实际 Markdown 语法预览起笔格式，可随选择更新。
- 「恢复默认」重置本页待保存的各层规则，保留开关状态。页底「保存」应用设置，「取消」丢弃本次设置修改。
- 「统一当前文件格子格式…」是区域内单独的按钮。当前文件已有有效预设，且预设或最大层级的修改已保存时，按钮可用。说明文字提示此操作会处理当前文件的已有格子。

## 2. 层级、正文和 YAML

层级由 `section` 编号的段数决定。`1`、`2` 均为第一层，`1.1`、`1.8`、`2.3` 均为第二层。`1.1` 在子九宫格界面里显示为中心格时仍为第二层。布局、显示位置和当前子宫主题都与层级无关。

### 与当前文件的最大层级联动

- **指定上限 N**时，直接显示第 1 到第 N 层的全部规则。例如上限 2 显示 `1`、`1.1`，上限 5 显示第 1 到第 5 层，上限 7 显示第 1 到第 7 层。此模式只有逐层规则。
- **不设上限**时，初次显示前 3 层，以及一行「第 4 层及更深」。这行可以设成任意 H1–H6 或关闭标题，正文也可照常选择。默认关闭标题，正文为无序列表。未单独添加的第 4 层及之后各层直接使用这条共用规则。
- 加号只在不设上限时出现。点击「＋ 设置第 4 层」后，新增第 4 层独立规则，初始值复制共用规则。共用规则随即改为「第 5 层及更深」，下一次可增加第 5 层。继续点击可以单独设置第 6、7 层及以上，标题选项仍为 H1–H6 或关闭。保存后重新打开设置，已添加的层级继续显示。
- 最大层级使用本页当前有效输入实时更新规则行。调低上限会隐藏超出范围的规则，并保留已配置值和已有格子。重新调高上限或切回不设上限时，恢复显示相关规则。切换模式时保留共用规则和单独配置过的层级，有限模式中仅按默认显示的行无需保存为单独配置。沿用现有的创建上限，明确执行统一格式时仍按规则处理整个文件里实际存在的 section，包括超过当前创建上限的旧格子。
- 「核心格子编号范围（1 ~ n）」限制第一段编号，层级界面只从「子九宫最大层级（含核心层）」取值。

以下是有限模式下每层的内置默认。不限模式的前 3 层用相同默认，其他层通过共用规则起笔，或在点击加号后单独指定。

| section 示例 | 层级 | 默认标题 | 默认正文 |
| --- | --- | --- | --- |
| `1` | 第 1 层 | H2 | 无序列表 |
| `1.1` | 第 2 层 | H3 | 无序列表 |
| `1.1.1` | 第 3 层 | H4 | 无序列表 |
| `1.1.1.1` | 第 4 层 | H5 | 无序列表 |
| `1.1.1.1.1` | 第 5 层 | H6 | 无序列表 |
| `1.1.1.1.1.1` | 第 6 层起，每层一行 | 关闭标题 | 无序列表 |

每一行都可选 H1–H6 或「关闭标题」。默认层级关系允许用户覆盖，例如各层都设 H4，或只让前三层带标题。启用标题时，首行写标题，正文从第二行开始。关闭标题时，正文从第一行开始。

| 正文选项 | YAML 值 | Markdown 起笔 |
| --- | --- | --- |
| 普通段落 | `paragraph` | 直接输入 |
| 无序列表 | `unordered-list` | `- ` |
| 有序列表 | `ordered-list` | `1. ` |

文件预设采用独立的顶层键 `mandala_cell_format`，与 `mandala_settings`、`mandala_day_plan` 并列。现有文件设置代码会整体替换 `mandala_settings`。最大层级仍取自现有设置 `mandala_settings.view.subgridMaxDepth` 及其默认值。下例是不限模式，仅单独设置前三层，其余层关闭标题。把 `deeper.heading` 改成 `4`，其余层就统一使用 H4。

```yaml
---
mandala: true
mandala_settings:
  view:
    subgridMaxDepth: unlimited
mandala_cell_format:
  enabled: true
  levels:
    '1': { heading: 2, body: unordered-list }
    '2': { heading: 3, body: unordered-list }
    '3': { heading: 4, body: ordered-list }
    deeper: { heading: none, body: unordered-list }
---
```

- `enabled` 为布尔值。运行时只在 `enabled: true` 时套用规则。缺键、显式 `false` 或无法读出的配置按关闭处理。
- `levels` 的数字键代表明确保存的深度，可大于 `6`。当用户在不限模式点击加号并保存，新层的数字键应写入，即使内容和共用规则相同。不限模式显示到最大已保存的独立深度，至少显示前 3 层。若中间某个深度没有单独保存，仍沿用该深度的默认规则。
- 规则读取优先使用具体数字键。缺省规则在有限模式下按上表补齐，在不限模式下前 3 层按上表补齐、第 4 层起使用 `deeper`。`deeper` 自身缺省时使用关闭标题与无序列表。字段只写了一部分时，各字段按同一优先级补齐。
- `heading` 接受整数 `1`–`6` 或字符串 `none`。`body` 接受表中的三个字符串。已提供的非法值在面板中提示用户修正，统一格式按钮在配置有效前不可用。编辑器遇到非法规则时沿用对应格子的原有编辑方式。
- 用户在文件设置页明确关闭并保存时，移除 `mandala_cell_format`。下次开启从内置默认值开始。旧文件没有此键时，保存无关设置仍保留缺键状态。
- 预设保存仅修改目标键。其他 YAML 属性的值、格子正文和 `section` 标记保留。旧文件可原地增加该键，文件路径和视图状态继续沿用现有机制。
- 只改预设时无需重写视图、日计划或模板配置。尤其留意当前文件设置的保存逻辑会触发日期标题刷新，把这个副作用限定在相关日计划设置实际变化时。其余日计划设置的现有保存语义继续保留。

## 3. 空格起笔和原稿保护

1. 用户从九宫格打开一个格子时，先安全解析当前格子的真实 `section` 编号和原始内容，再读取源 `.md` 的文件预设。格子内容为空或仅有空白时才应用。已有标题、段落、列表、注释等都算已有内容。原有空位和之后新增的空格用相同规则。用户手动清空并提交后，该格可在下次打开时重新使用预设。
2. 有标题时光标放在标题前缀后，写完标题回车进入配置的正文形式。无标题时光标从正文起笔处开始。有序和无序列表后续编辑沿用 Obsidian 的正常 Markdown 编辑行为。预设只初始化本次编辑，不充当强制格式校验，用户可以改写标题或正文的类型。
3. 自动生成的空标题或空列表前缀只是草稿。打开后退出，或保留空占位直接保存，源文件不产生占位符。只填标题后保存，只写标题。直接跳过标题去写正文时，保存实际正文并去掉空标题。清理只作用于本次新格草稿生成的占位，已有格子的同类 Markdown 原样通过。标题已保存后再次打开，按原有编辑行为处理。
4. 捕获原始内容、规则和草稿初始位置时以本次编辑会话为单位。全局或文件预设的后续修改在下一次打开空格时生效。退出、切换和保存沿用现有会话生命周期。桌面多窗格和移动端回写都必须保留其他格子、最新 YAML 以及现有冲突保护。
5. 年度日计划的日期中心格继续由日计划接管标题与光标定位。预设不能抢先插入通用标题，也不能改动日期标题。周边格在现有每日模板机制运行后、且源内容仍为空时，可以使用文件预设。普通模板应用、格子移动和交换仍按各自的现有规则处理。

示例。第二层配置 H4 和有序列表，填写标题和正文后保存的内容如下。

```md
<!--section: 1.1-->
#### 周读书计划
1. 读完第一章
```

如果只填写标题，保存到源文件的内容到 `#### 周读书计划` 为止。保存时沿用仓库现有的 section 边界和换行处理。

## 4. 显式统一当前文件的格子格式

### 流程与写入范围

1. 点击按钮时读取当前文件最新的 Markdown 和已保存的 `mandala_cell_format`，按整个文件的真实 `section` 计算结果，包含当前视图尚未展开的子宫和核心格。空格保持空白。年度日计划的日期中心格整格跳过。首个 section 标记之前的普通 Markdown、YAML 和所有 section 标记保留。这个动作可以改动已有格子，它和「保存设置」是两个独立操作。
2. 展示确认，包含文件名、待修改格子数和因复杂内容等原因跳过的格子数，并说明会改动已有 Markdown。若计划取消已有标题，同时提示指向这些标题的链接可能失效，原有链接文本保持原样。无改动时显示结果，无需发起写入。同一操作只允许有一个待确认或正在写入的请求。
3. 确认后用一次 `vault.process` 在最新原文上批量写入。以预览时的有效规则（包含最大层级）、section 标记和目标格原文为校验依据。文件已切换、预设、最大层级或 section 结构已改变、目标格原文冲突时，整批取消并提示重新预览。其他 section 的并发内容修改保留。沿用现有文件保存及同步机制，确保变更在同一文件的其他窗格可见，且旧草稿无法盖回批量修改。
4. 显示实际修改和跳过的格数。已符合规则的格子保持原文。用同一配置重复执行的结果应为零改动。

### 保守转换规则

实施范围覆盖可安全识别的普通标题、简单段落和扁平列表。只改格式所需的 Markdown 符号和换行，保留文本、行内样式、链接和顺序。任一必要转换无法安全完成时整格跳过。以下规则给实现划定边界。

| 场景 | 处理方式 |
| --- | --- |
| 第一处非空行是明确、带文字的 ATX 标题 | 有目标级别时只调整标题前缀。目标为关闭标题时保留标题文字，作为第一个正文段落或列表项。原正文是同类的简单列表时也适用，标题文字排在已有项目之前，有序列表从 `1. ` 重新编号 |
| 需要添加标题且原文首段是一行独立的普通文字 | 可将这行提升为标题。第一块是列表、引用、代码，或首段多行时跳过，避免猜测标题 |
| 简单段落转列表 | 每个空行分开的单行普通段落成为一个列表项。无序用 `- `，有序从 `1. ` 开始 |
| 扁平列表互转 | 保留每项内容和顺序，只替换项目符号或序号。已有列表类型与目标一致时保留现有符号或序号 |
| 扁平列表转段落 | 移除项目标记，项目之间留一个空行，确保各自成段 |
| 需要转换的正文含嵌套项、任务复选框、续行、代码、引用或 callout、表格、块 ID、HTML 块等 | 整格跳过并计入提示。首行含复杂结构、Setext 标题、正文块类型混用或无法可靠判断时同样跳过 |

已经符合规则的内容可直接保留，即使使用了复杂 Markdown。转换后如果文字会意外变成另一种块结构，也跳过该格。例如列表项内容以 `# ` 开头时，去掉项目标记会使它变成标题。为识别简单情形补足边界和反例测试即可，无需引入 Markdown 依赖或扩写成通用转换器。已有「格式化标题」菜单仍是原来的单独功能，它会按自己的规则调整所有可识别的标题，不能复用为这个新按钮的写入实现。

## 6. 验收与回归验证

| 验收场景 | 预期 |
| --- | --- |
| 全局默认关闭，升级后打开旧文件 | 默认编辑流程照旧，文件无新增预设字段 |
| 打开全局开关，从命令或文件夹菜单新建普通九宫格，另新建日计划九宫格 | 各新文件获得默认预设。已有文件保留原配置 |
| 全局关闭后，先前启用的文件继续编辑，再新建一份文件 | 先前启用的文件依照自己的 YAML 起笔，新文件默认关闭 |
| 旧 `.md` 已填写一半，从命令面板在文件设置页启用，切到视图选项重新打开设置 | 两个入口显示同一份配置。已填格子的 Markdown 不变，空位使用预设 |
| `1` 与 `2`、`1.8` 与 `2.3`，子格作为视图中心 | 分别按真实编号的深度取规则，视图位置不改变层级 |
| 最大层级设为 2、5 或 7 | 立即显示对应数量的层级行，有限模式无加号，第 6、7 层也可独立指定 H1–H6 或关闭标题 |
| 最大层级不限，未点击加号，设置共用规则为 H4 或关闭标题 | 前 3 层独立显示，第 4 层及之后全部使用共用设置 |
| 不限模式下逐层添加第 4、5 层，保存并重开 | 第 4、5 层各有独立规则，第 6 层及之后使用共用设置，可继续加第 6 层及以上 |
| 调低上限、保存，再调回原值或不限 | 已有格子和深层自定义规则保留，隐藏行按新的上限恢复显示 |
| H4、关闭标题、三种正文形式 | 标题级别独立可选。关闭标题时三种正文均从第一行起笔 |
| 打开空格直接退出、未填写就保存、只写标题后保存、跳过标题只写正文 | 不写空占位，部分填写只保存实际内容 |
