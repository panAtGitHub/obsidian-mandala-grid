# Mandala Grid 使用场景与数据规则

这份手册记录已确认的产品约定，供修改和审查代码时使用。

## 九宫格专属 Markdown

每个格子的内容由一个 `section` 标记界定，从该标记之后到下一个标记之前。
首个标记之前的文字在格子范围之外。九宫格视图及格子内容导出按这个范围读取。

## 年度日计划

- 每天对应一个中心格。第一行是插件管理的日期标题，用户记录写在日期标题下方。
- 打开某一天时可以补齐日期标题。保存日期格式设置时可以刷新已有日期标题。
  这两种操作都要保留标题下方的用户记录。
- 在九宫格菜单应用每日模板时，只更新模板配置，保留已有日期记录。
  显式执行「更新历史标题」时，只更新指定日期范围的格子标题，保留正文。

## 桌面双窗格与格子编辑

- 常见工作流是打开同一份年度日计划，左边补写过去某天，右边继续写今天。
  两个窗格各自保留所选日期和选中格。
- 每次编辑一个格子。保存快捷键只提交当前编辑格对应的 `section`。
  同一文件其他格子的内容必须保留。
- 切换窗格、选择其他格子、执行其他九宫格命令或退出编辑时，直接丢弃未提交的草稿。

## 普通九宫格模板

应用模板可以整格替换当前主题的周边八格，包含原有标题和正文。模板中的空格
可以清空对应的旧格。中心格保留原内容。

## 审查数据改动

先确认用户执行的操作和该操作允许改动的数据范围，再检查实现和测试。
复现优先使用本手册记录的工作流。发现文档未定义的场景时，先确认预期，
再判断是否属于误删。
